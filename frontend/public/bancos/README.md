# Logotipos de instituições financeiras

Arquivos locais usados somente para identificar a instituição em sugestões e contas.
Não representam integração bancária, certificação, parceria ou endosso ao sistema.
As imagens não foram redesenhadas, recoloridas ou deformadas.

## Origem e condições consultadas

As dez imagens foram obtidas das páginas de arquivo do Wikimedia Commons.
Essas páginas identificam os titulares e, em sua maioria, remetem a sites ou materiais
das próprias instituições. A origem exata de cada arquivo, crédito/autor informado
pela fonte, classificação de copyright, URL original, data de verificação e hash
SHA-256 estão em [fontes.json](fontes.json).

| Arquivo | Instituição | Classificação declarada pelo Commons |
|---|---|---|
| banco-do-brasil.svg | Banco do Brasil | Public domain / logotipo simples |
| bradesco.svg | Bradesco | Public domain / logotipo simples |
| inter.svg | Banco Inter | Public domain / logotipo simples |
| btg-pactual.svg | BTG Pactual | Public domain / logotipo simples |
| banrisul.svg | Banrisul | Public domain / logotipo simples |
| caixa.svg | Caixa Econômica Federal | Public domain / logotipo simples |
| itau.svg | Itaú | CC0 |
| nubank.svg | Nubank | Public domain / logotipo simples |
| santander.svg | Santander | Public domain / logotipo simples |
| sicredi.svg | Sicredi | Public domain / logotipo simples |

Essa classificação é a informação da fonte sobre copyright, não uma licença de
marca concedida pelos bancos. As marcas continuam pertencendo a seus titulares.
O Commons também distingue copyright de [restrições de marca](https://commons.wikimedia.org/wiki/Commons:Non-copyright_restrictions).
Os [termos do Itaú](https://www.itau.com.br/termos-de-uso), por exemplo, reservam
o uso de seus sinais distintivos à autorização prévia; o registro CC0 do arquivo
no Commons não substitui essas condições nem significa autorização do banco.

O uso previsto neste código é nominativo, junto do nome da instituição, em uma
interface de controle financeiro. Não usar estes arquivos como marca do projeto,
em co-branding ou em publicidade que sugira vínculo com os titulares.
Este registro documenta a verificação das fontes; não declara uma autorização
individual dos titulares ou uma liberação geral para qualquer finalidade.

## Manutenção

- Conferir a página de origem antes de substituir uma versão da marca.
- Preservar proporção e cores da arte; a apresentação usa object-fit: contain.
- Conferir o SHA-256 ao substituir os arquivos e atualizar fontes.json.
- Não usar hotlink: a aplicação serve exclusivamente os arquivos de /bancos/.
- Se uma imagem falhar, a interface mostra o ícone genérico de conta.

O catálogo e os aliases estão em src/app/features/contas/catalogo-bancos.ts.
A identificação é derivada do nome; nenhum campo de marca é enviado à API.
